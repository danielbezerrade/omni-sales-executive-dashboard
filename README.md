📊 Omni - Dashboard Executivo de Vendas

Este projeto é um Dashboard Executivo de BI completo desenvolvido para a empresa Omni, com foco em inteligência de vendas e tomada de decisão estratégica.

💡 Nota: A base de dados foi gerada inteiramente via Inteligência Artificial (IA) para fins de simulação comercial e testes analíticos.

🎯 Destaques do Projeto

Design e Layout (PowerPoint): Todo o design de fundo e a disposição dos cartões foram criados no Microsoft PowerPoint para garantir uma interface moderna e profissional.

Modelagem & DAX: Estruturação em Star Schema e utilização de fórmulas DAX para calcular KPIs de faturamento, margem de lucro e um ranking dinâmico com a função RANKX (Top 10 Produtos).

Data/Hora Dinâmica de Atualização: Criação de uma consulta no Power Query utilizando DateTime.LocalNow(). Com isso, toda vez que o Power BI atualiza, o relatório mostra o horário exato da última atualização.

📌 Estrutura do Painel

KPIs Principais: Faturamento Total, CMV, Lucro Total, Margem % e Ticket Médio.

Visuais Analíticos: Linha de tendência mensal de vendas e gráfico de barras com Top 10 Produtos.

Detalhamento Operacional: Tabela com indicadores completos por produto.

Filtros Interativos: Segmentação por Ano, Mês e Categoria.

🛠️ Tecnologias Utilizadas

Power BI Desktop (Modelagem, DAX e Relatório);

Power Query (Tratamento de dados e carimbo de atualização);

Microsoft PowerPoint (Design de layout e UI/UX);
